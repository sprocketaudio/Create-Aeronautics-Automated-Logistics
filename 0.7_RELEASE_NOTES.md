# Create Aeronautics: Automated Logistics 0.7

Version 0.7 expands the information available from Airship Stations, with live Display Link output and broader map support. It also adds new Cargo Link integrations for several popular Create addons. Underneath those visible additions are extensive reliability improvements for autonomous docking, cargo waits, queues, and recovery after world reloads.

## Safer cargo waits and docking

- Cargo conditions now include items and fluids staged inside linked Docking Connectors. Ships no longer depart merely because the main linked storage emptied before the transfer crossed the dock.
- New cargo conditions default to requiring a stable result for two seconds, reducing apparent false completions caused by brief transfer gaps.
- Improved hand-off of items already buffered in a connector before the physical dock finishes locking.
- Removing a linked Docking Connector now clears the stale dock link and station redstone output instead of leaving the automation in a misleading state.
- Dock queues now continue to treat stopped, paused, or faulted ships inside the protected dock area as occupying the dock.
- Physical dock occupancy survives world reloads and temporary vehicle-restoration gaps.
- Broken docking connections are now restored automatically after reloading a world, allowing item and fluid transfer to resume.
- Restarting a stopped ship retains departure clearance until that ship has physically left the dock area, preventing the next queued ship from approaching too early.
- Improved recovery when a connector is removed and rebuilt while a vehicle is docked or restoring.

## Airship Station displays

Airship Stations can now provide live information to Create Display Links.

- The station-wide view shows live inbound and outbound vehicle counts, including queued arrivals, alongside vehicles at the station, current dock state, and queue length.
- Dock state distinguishes between free, approaching, occupied, and departing states.
- Boards can be filtered to one known vehicle to show its location or journey, next station, and a labelled status such as travelling, arriving, departing, docked, or queued.
- The vehicle picker suggests vehicles with routes connected to that station and respects normal ownership, permission, and FTB Teams access rules.
- When Jade is installed, station tooltips show the station name and Ship Transponder tooltips show the ship name.

## Expanded map support

- Added automated vehicle markers to Xaero's Minimap and Xaero's World Map.
- Added separate client toggles for the FTB Chunks, JourneyMap, and Xaero map integrations.
- Added a shared map-marker size setting. Marker labels scale gently with their icons to remain readable.
- Improved the Logistics Terminal's tabletop map with steadier line widths, less glare, clearer route colours, and vehicle icons rendered above routes and station markers.

## More Cargo Link targets

Cargo Links now additionally support:

- Create: Connected Item Silos, including their vertical multiblock sizes.
- Create: Iron Vaults storage variants.
- Propulsion: Simulated Platinum Tanks.

Missing linked cargo blocks are now removed from saved links automatically when their loaded position no longer contains supported storage.

## Recorded-route animation polish

- Added Mechanical Bearing animation during automated playback, allowing attached sails and other bearing contraptions to visibly rotate along a recorded route.
- Retuned the existing automated Small Propeller and Propeller Bearing animations: large propeller types now run faster while small propellers use a calmer speed.
- Propellers and bearings now ramp up and down smoothly when a vehicle starts, stops, or waits instead of snapping instantly between motion and rest.
- These animations are visual only and do not add propulsion or alter the vehicle's machinery.
- Updated the optional Simurail bogey animation bridge for both the previous and current bogey APIs.

## What's next: Redstone Drive

Substantial foundations for the future **Redstone Drive** system were developed during 0.7, including Drive Modules, calibration, route guidance, and real redstone control of player-built propulsion. The public Advanced Transponder and Drive Module items are deliberately unavailable in 0.7 while the feature receives further design work and testing.

Normal recorded-route playback remains the supported automation mode in this release.
